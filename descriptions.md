### Описание столбцов таблицы application_{train|test}.csv

* **SK_ID_CURR** — Уникальный идентификатор кредита (заявки) в выборке.
* **TARGET** — Целевая переменная (1 — у клиента возникли трудности с выплатами: просрочка более X дней хотя бы по одному из первых Y платежей по кредиту в нашей выборке, 0 — все остальные случаи).
* **NAME_CONTRACT_TYPE** — Тип кредита (наличные или возобновляемый/карта).
* **CODE_GENDER** — Пол клиента.
* **FLAG_OWN_CAR** — Флаг: владеет ли клиент автомобилем.
* **FLAG_OWN_REALTY** — Флаг: владеет ли клиент недвижимостью (домом или квартирой).
* **CNT_CHILDREN** — Количество детей у клиента.
* **AMT_INCOME_TOTAL** — Общий доход клиента.
* **AMT_CREDIT** — Итоговая сумма кредита по заявке.
* **AMT_ANNUITY** — Ежемесячный платеж по кредиту (аннуитет).
* **AMT_GOODS_PRICE** — Стоимость товара, под покупку которого берется потребительский кредит.
* **NAME_TYPE_SUITE** — Кто сопровождал клиента при подаче заявки на кредит.
* **NAME_INCOME_TYPE** — Тип занятости/источник дохода клиента (бизнесмен, работающий, декретный отпуск и т. д.).
* **NAME_EDUCATION_TYPE** — Уровень максимального образования, полученного клиентом.
* **NAME_FAMILY_STATUS** — Семейное положение клиента.
* **NAME_HOUSING_TYPE** — Жилищные условия клиента (аренда, живет с родителями и т. д.).
* **REGION_POPULATION_RELATIVE** — Нормализованная плотность населения региона проживания клиента (более высокое значение указывает на более высокую заселенность региона).
* **DAYS_BIRTH** — Возраст клиента в днях на момент подачи заявки.
* **DAYS_EMPLOYED** — Количество дней текущего стажа работы на момент подачи заявки.
* **DAYS_REGISTRATION** — Количество дней с момента изменения регистрации до подачи заявки.
* **DAYS_ID_PUBLISH** — Количество дней с момента получения документа, удостоверяющего личность, с которым клиент подавал заявку, до дня подачи заявки.
* **OWN_CAR_AGE** — Возраст автомобиля клиента в годах.
* **FLAG_MOBIL** — Предоставил ли клиент номер мобильного телефона (1 = ДА, 0 = НЕТ).
* **FLAG_EMP_PHONE** — Предоставил ли клиент рабочий номер телефона (1 = ДА, 0 = НЕТ).
* **FLAG_WORK_PHONE** — Предоставил ли клиент домашний/стационарный телефон (1 = ДА, 0 = НЕТ).
* **FLAG_CONT_MOBILE** — Был ли доступен мобильный телефон для связи (1 = ДА, 0 = НЕТ).
* **FLAG_PHONE** — Предоставил ли клиент телефонный номер (1 = ДА, 0 = НЕТ).
* **FLAG_EMAIL** — Предоставил ли клиент адрес электронной почты (1 = ДА, 0 = НЕТ).
* **OCCUPATION_TYPE** — Профессия/должность клиента.
* **CNT_FAM_MEMBERS** — Количество членов семьи клиента.
* **REGION_RATING_CLIENT** — Оценка банком региона проживания клиента (1, 2, 3).
* **REGION_RATING_CLIENT_W_CITY** — Оценка банком региона проживания клиента с учетом города (1, 2, 3).
* **WEEKDAY_APPR_PROCESS_START** — День недели, в который клиент подал заявку на кредит.
* **HOUR_APPR_PROCESS_START** — Приблизительный час подачи заявки на кредит.
* **REG_REGION_NOT_LIVE_REGION** — Флаг несоответствия адреса регистрации адресу фактического проживания на уровне региона (1 = отличаются, 0 = совпадают).
* **REG_REGION_NOT_WORK_REGION** — Флаг несоответствия адреса регистрации адресу работы на уровне региона (1 = отличаются, 0 = совпадают).
* **LIVE_REGION_NOT_WORK_REGION** — Флаг несоответствия адреса фактического проживания адресу работы на уровне региона (1 = отличаются, 0 = совпадают).
